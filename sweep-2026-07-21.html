Method

Read-only throughout: public item-page loads and gallery image downloads only — no logins, bids, watches, offers, or messages. Plain curl gets an Akamai 403 on eBay item pages from the cloud agent environment, so pages were loaded via headless Chromium (Playwright) with a proxy TLS-compatibility policy (see ebay-access.md); gallery photos were pulled at full s-l1600 resolution from each page's embedded media list and zoom-cropped for squad-level inspection. Seven agents ran in parallel; no captchas or throttling. Where a worker hedged a tier (two lots), the note says so and the tier field uses the strict scale.

The tier scale

Tier Means
PRIMER-ONLY Nothing finished — sprayed or bare plastic. Kit value only.
PARTIAL Any squad or model flat grey/black or unpainted → not a finished army (a project buy).
Basic Block colours, no wash, bare or flat bases.
Tabletop Base + wash, bases done.
Tabletop+ Edge highlights, cohesive scheme, detailed bases.
High TT / Display Blending, freehand, OSL, showcase basing.

Flags worth calling out on any listing: 3D prints, merged/mixed schemes, damage, ENDED/SOLD, and auction-vs-BIN (a current bid is not a price).
